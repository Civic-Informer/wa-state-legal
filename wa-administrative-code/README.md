# Washington Administrative Code (WAC)

This directory holds a snapshot of every published Title of the Washington Administrative Code — 227 Titles spanning every state agency, board, commission, college, and university that promulgates Washington regulations (Accountancy Board, Ecology, Health, Labor & Industries, Licensing, Revenue, Insurance Commissioner, the WSU/UW/WWU/CWU systems, all 25 community-college districts, all five technical colleges, etc.) — together with a Claude Code skill that navigates and cites them. The directory IS the distributable skill bundle: it contains the consolidated markdown regulation text plus per-Title README playbooks and a root router (`SKILL.md`). The body text came from `pdftotext -layout` over the Washington State Legislature's official per-chapter COMBINEDCHAPTER PDFs (the canonical full-text source) and has been spot-checked against the source for fidelity. The raw PDFs, HTML index pages, and General Index that the corpus was built from are not redistributed with this skill — see "Provenance" below if you want to re-derive the corpus.

To use it, copy this directory into `~/.claude/skills/wac/` (renaming to `wac` if you prefer). Claude picks the skill up automatically whenever a user cites or paraphrases Washington regulation — `WAC 308-93-280`, `WAC 246-840`, `WAC 132A-104`, `Chapter 458-20 WAC`, "Washington vehicle title rules," "DOL licensing fees," "Ecology water-quality regs," "L&I safety standards," etc. On a match, Claude reads the root `SKILL.md`, routes to the relevant Title's `README.md`, and answers from the on-disk markdown. It does not (and should not) fetch from the web — the local files are authoritative for this skill and reflect a snapshot dated 2026-05-20.

**Scope:**

- **In:** all 227 published WAC Titles — every state agency's adopted rules: Accountancy, Agriculture, Air Pollution, Archaeology, Banking, Cannabis (LCB), Children/Youth/Families, Commerce, Corrections, Criminal Justice Training, Ecology, Education (SBE/OSPI), Employment Security, Enterprise Services, Financial Institutions, Fish & Wildlife, Forest Practices, Gambling, Health, Higher Ed Coordinating, Horse Racing, Human Rights, Insurance Commissioner, Labor & Industries, Licensing (DOL), Liquor & Cannabis, Lottery, Military, Natural Resources, Nursing, Parks & Rec, Pharmacy, Public Disclosure Commission, Public Employment Relations, Public Records, Public Works Board, Real Estate Appraisers, Retirement Systems, Revenue, Secretary of State, Social & Health Services (DSHS), State Patrol, Tax Appeals, Transportation (WSDOT), Utilities & Transportation Commission (UTC), Veterans Affairs, Workforce Training, and more.
- **In:** all 25 community-college districts (Title 132A through 132Z), all five technical colleges (Title 495A-E), the four-year regional universities (Central, Eastern, Western, Evergreen), and the research universities (WSU at 504, UW at 478).
- **In:** **2,825 chapters of full regulation body text** across 174 active Titles — every section, subsection, definition, history note, statutory authority cite, and disposition-of-rescinded-sections table the Legislature publishes in the 2025 archive's per-chapter COMBINEDCHAPTER PDFs.
- **In (degraded):** 1 single chapter (`WAC 237-990`, Natural Resources – Determination of Geographic Names appendix) that returned 404 from the Legislature's server at snapshot time — `rules.md` carries a placeholder noting the permanent gap.
- **In (empty):** 52 Titles with no active chapters in the 2025 archive — these are historical/superseded agency designations whose rules have all been rescinded or recodified elsewhere. Each carries a README documenting the empty state.
- **Out:** RCW enabling statutes (separate sibling skills at `../wa-rcw-1-50/` (skill `rcw-1-50`, RCW Titles 1–50 plus lettered variants) and `../wa-rcw-51-100/` (skill `rcw-51-100`, RCW Titles 51–91 plus lettered variants)) — WAC rules implement RCW statutes; the corresponding `RCW {chapter}` citation appears inline in every WAC section's statutory-authority bracket, but the RCW text itself lives in those other skills.
- **Out:** Washington court rules — statewide (`../wa-state-court-rules/`), county Superior Court local rules (`../wa-county-superior-court-rules/`), District Court local rules (`../wa-district-court-rules/`), and Municipal Court local rules (`../wa-municipal-court-rules/`).
- **Out:** Federal regulations (CFR), federal statutes (USC), and case law interpreting the WAC.
- **Out:** Municipal/county ordinances (these are separate codes, not part of the state WAC).
- **Out:** Pre-2025 historical WAC versions and the underlying agency rulemaking dockets / WSR (Washington State Register) filings — only the codified 2025 snapshot is archived (history-note brackets *inside* each section still cite the originating WSR numbers).
